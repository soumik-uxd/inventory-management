Architecture overview

Factory Inventory Management System

A Vue 3 single-page app talks to a FastAPI service over HTTP. The service keeps every dataset in memory, loaded once from JSON files at startup. There is no database, no auth, and nothing is persisted.

  • :3000 Vite dev server
  • :8001 FastAPI / Uvicorn
  • 13 GET routes under /api
  • 7 JSON data files
  • 2 locales (en, ja)
System architecture

Three tiers, one process each side

The browser holds all UI state. The API is stateless per request except for the module-level data lists it filters.

Data flow

What happens when a filter changes

The four filters (Time Period, Warehouse, Category, Order Status) live in one shared module, so every view reads the same selection.

  1. The user picks a value in FilterBar.The select writes to a module-level ref in useFilters. The refs are created outside the function, which makes them a singleton shared across all views.client/src/composables/useFilters.js
  2. The active view reloads.Each view watches the refs it cares about and calls its own loadData() when one changes. Dashboard and Orders watch all four; Spending watches only the time period.e.g. client/src/views/Dashboard.vue · watch([...]) → loadData()
  3. Filters become request params.getCurrentFilters() returns { warehouse, category, status, month }. The Time Period value is sent as month.useFilters.getCurrentFilters()
  4. api.js sends the request.Any value equal to "all" is left out, the rest go into a URLSearchParams query string, and axios issues a GET to localhost:8001/api.client/src/api.js
  5. FastAPI filters the in-memory list.apply_filters matches warehouse exactly and category and status case-insensitively. filter_by_month then does a substring match on order_date, expanding Q1-2025 style values through QUARTER_MAP.server/main.py · apply_filters, filter_by_month
  6. The response is validated.Routes with a response_model serialize through Pydantic. Summary, spending and report routes return plain dicts.server/main.py · response_model=List[...]
  7. The view derives what it shows.Raw responses go into refs such as allOrders and inventoryItems. KPIs and chart geometry are computed properties, and formatCurrency converts to yen when the locale is Japanese.computed() · client/src/utils/currency.js

Places where the tiers disagree

These come from reading the code as of the current branch. None of them stop the app from loading.

Missing

Task endpoints don't exist on the server

App.vue calls GET/POST /api/tasks and PATCH/DELETE /api/tasks/{id}. main.py defines none of them, so these return 404. The error is caught and logged to the console.

Missing

Purchase order endpoints are client-only

api.js defines createPurchaseOrder and getPurchaseOrderByBacklogItem, but nothing calls them and the server has no matching routes. The Dashboard attaches PO data to backlog items in local state only.

Unrouted

Backlog view has no route

views/Backlog.vue exists but isn't registered in main.js, so it can't be reached. Backlog data is shown on the Dashboard instead.

Inconsistent

Reports bypasses the API client

Reports.vue calls axios with a hardcoded http://localhost:8001 URL instead of going through api.js.

Note

Quarter filters are server-side only

The backend accepts Q1-2025 through Q4-2025, but FilterBar only offers single months.

Note

Backlog count ignores filters

/api/dashboard/summary returns total_backlog_items from the full list, whatever filters are set.
